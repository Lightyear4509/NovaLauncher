# Contributing to NovaLauncher

NovaLauncher is MIT licensed and welcomes focused issues and pull requests.
Before submitting code, run the locked restore, formatting check, Debug and
Release builds, and all tests described in the build guide. Never include game
files, Steam credentials, personal library data, telemetry, downloaded-code
execution, or a safeguard/test reduction. Security reports belong in the
private channel described in `SECURITY.md`, not a public issue.

By contributing, you agree that your contribution is licensed under the MIT
License in this repository and may be credited to NovaLauncher Contributors.
