# Security Policy

The alpha preview is not yet a supported release. Please do not open a public
issue for a suspected vulnerability. Until a dedicated private GitHub security
advisory channel exists, retain the report and contact the repository owner
privately. Do not send credentials, game saves, or copyrighted game content.

NovaLauncher never needs Steam credentials and must never modify Steam files.
The current build has no telemetry, plugin execution, cloud synchronization,
ROM acquisition, or downloaded-code execution.
