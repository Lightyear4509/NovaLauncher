# NovaLauncher unsigned preview notice

This build is an experimental, digitally unsigned preview.

- Windows cannot authenticate its publisher and may display **Unknown publisher** or a Microsoft Defender SmartScreen warning.
- Download it only from the official `Lightyear4509/NovaLauncher` GitHub release.
- Verify the complete SHA-256 value against `SHA256SUMS.txt` before opening it.
- Do not disable Windows security protections globally.
- Automatic update installation and signed rollback are unavailable because this build intentionally contains no trusted publisher-certificate pin.
- Keep independent backups of valuable launcher data and game saves.

The source code is available under the MIT License. An unsigned executable is not equivalent to a malicious executable, but its publisher identity cannot be authenticated by Windows.
