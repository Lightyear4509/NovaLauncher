# NovaLauncher Project Bible

> Last Updated: July 2026

---

# Vision

NovaLauncher aims to become the most polished, customizable, and developer-friendly open-source game launcher.

The goal is to provide one application capable of launching every game regardless of platform while remaining beautiful, fast, extensible, and community-driven.

---

# Mission

One launcher.

Every platform.

Unlimited customization.

---

# Project Philosophy

NovaLauncher should always prioritize:

1. Simplicity
2. Performance
3. Reliability
4. Extensibility
5. Clean Architecture

Every feature should answer these questions:

- Does this make the launcher easier to use?
- Does this make future development easier?
- Can this become a plugin?
- Does it keep the UI responsive?
