# NovaLauncher 1.2.0 unsigned preview

NovaLauncher 1.2.0 introduces a focused, professional interface while preserving the launcher workflows qualified in 1.1.0.

## Highlights

- Separates save synchronization and backup work from game-folder transfer.
- Adds a dedicated Downloads & Sharing page for send, receive, active-transfer, and history workflows.
- Reworks Saves into a quieter operational page for save activity, snapshots, destinations, and backup.
- Replaces novelty themes with a single controlled Nova design system in Dark and Light modes.
- Introduces a clearer premium action hierarchy, restrained surfaces, consistent spacing, and vector navigation icons.
- Retains keyboard, controller, accessibility, trusted-device, integrity, and explicit-confirmation behavior.

## Distribution note

This preview is intentionally unsigned. Windows may show an unknown-publisher warning. In-app update installation and signed rollback remain unavailable and fail closed. Verify downloads with `SHA256SUMS.txt` before running them.
