# NovaLauncher Versions

> This is the canonical release plan. Historical plugin work is not part of the
> active product and does not establish a supported feature.

- [x] Steam Import
- [x] Library
- [ ] Artwork Providers
- [ ] SteamGridDB

---

## 0.2

- [ ] Metadata
- [ ] Collections
- [ ] Search Improvements

---

## 0.3

- [ ] ROM Scanner
- [ ] Emulator Manager

---

## 0.4

- [ ] First-party Steam achievements
- [ ] Achievement progress and per-game details UI
- [ ] Offline cache, refresh, cancellation, and privacy controls

---

## 0.5.0-alpha.1 — Integration foundation

- [ ] Stable first-party provider contracts
- [ ] Authorized-provider privacy and credential review
- [ ] Steam achievement provider with bounded cache
- [ ] First-party SteamGridDB adapter
- [ ] Emulator profile and ROM-import MVP for at least two emulators
- [ ] Experimental local cloud-save snapshot engine
- [ ] User-owned installer/import workflow only
- [ ] Responsive-window, migration, backup/export, and release gates

## 0.5.x alpha updates

- [ ] IGDB feasibility
- [ ] RetroAchievements first-party integration feasibility
- [ ] Ludusavi feasibility
- [ ] Nexus Mods feasibility
- [ ] Additional emulator profiles
- [ ] HowLongToBeat and ProtonDB only if authorized stable APIs are available

## 0.6.0-alpha — Seamless cloud saves

- [ ] Local version history and atomic restore
- [ ] Device identity, leases, and conflict handling
- [ ] End-to-end encryption
- [ ] Local folder/NAS transport
- [ ] Experimental Tailscale transport
- [ ] Pre-launch pull and post-exit push lifecycle

## 0.7.0-alpha — Authorized acquisition

- [ ] Secure resumable download manager
- [ ] Safe archive and installer staging
- [ ] User-owned installers and authorized first-party providers
- [ ] Post-install metadata, artwork, and save discovery
- [ ] Nexus Mods integration for mods
