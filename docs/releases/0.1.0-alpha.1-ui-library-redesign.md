# Library and launch UX preview

This post-Increment-8 preview responds to the first hands-on UI review. It is
not a new qualified release.

## Implemented

- Removed the global search, sort, favorite, and new-game controls from the top bar.
- Replaced the three-column library editor with a dedicated Library page and
  Steam-style game cards that open a separate details page.
- Added details for description, developer, publisher, release date, playtime,
  artwork, achievements, and launch actions.
- Added a native Windows `.exe` file picker. It derives the initial name and
  working directory, then requires review and an explicit save.
- Added atomic per-game playtime and last-played persistence for executable
  processes launched directly by NovaLauncher.
- Added a per-game administrator option. It uses Windows `runas` and always
  requires the normal UAC consent dialog. URI/storefront targets cannot request it.
- Added a Settings field for a SteamGridDB API key. The key is memory-only for
  the running session, is masked, is not logged, and is excluded from backups.
- Improved Steam preview so every skipped manifest displays both its path and
  reason before the user commits the atomic import.

## Steam diagnosis on the reference system

Steam was found at `C:\Program Files (x86)\Steam`. Eight manifests were readable.
Seven had existing installation directories and should import. The manifest for
App ID 3873750 referenced a missing bonus-content installation directory and is
correctly skipped. NovaLauncher never read credentials or modified Steam files.

## Limitations

- Steam launch URIs return the Steam client process rather than the actual game
  process, so NovaLauncher does not claim locally measured Steam playtime yet.
- SteamGridDB keys are intentionally not persisted until Windows Credential
  Manager storage, deletion, rotation, and recovery tests are implemented.
- Card artwork still uses the safe placeholder treatment; cover-image loading
  on every virtualized card remains a later performance/accessibility slice.
- UAC cannot and must not be bypassed. The launcher itself stays unelevated.
