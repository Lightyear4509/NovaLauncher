# 0.1.0-alpha.1 — Increment 4 enrichment foundation

This checkpoint is superseded by `0.1.0-alpha.1-increment-4.md`, which records
the completed bounded image-materialization and rendering slice.

This increment establishes metadata and artwork provider safety, merge, cache,
and atomic refresh behavior. It does not make NovaLauncher complete or packaged.

## Added

- Ordered first-party metadata and artwork contracts
- Provenance-aware deterministic metadata merge with manual precedence
- Fresh/stale/expired bounded LRU provider caches
- Atomic persist-before-publish enrichment coordination
- Bounded HTTPS, transient retry, timeout, redirect, content-type, and response
  size controls
- Steam storefront metadata normalization and Steam CDN artwork references
- Optional environment-key SteamGridDB cover lookup
- Deterministic cover/hero/logo/background placeholders
- Accessible normal and forced refresh actions and explicit result status

## Still required for artwork release readiness

- Bounded remote image byte download and format/dimension/pixel validation
- Managed local artwork installation and cleanup
- Safe visual artwork rendering in the Avalonia UI

No achievements, plugins, cloud saves, ROM acquisition, telemetry, or
downloaded-code execution is included.
