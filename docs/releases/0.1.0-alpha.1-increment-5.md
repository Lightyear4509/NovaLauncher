# 0.1.0-alpha.1 — Increment 5 first-party achievements

## Delivered

- Stable provider/API-name achievement identities
- Documented read-only Steam player and schema requests
- Explicit environment opt-in; secrets and raw account ID are not persisted or logged
- Atomic versioned `achievements.json` cache with account-fingerprint separation
- Fresh, stale, offline, private, unavailable, malformed, rate-limit, and cancellation states
- Unlocked counts, completion percentage, provider attribution, and unlock times
- Accessible per-game refresh and achievement list

No achievement write API, inferred unlock, scraping, plugin, cloud save,
telemetry, or downloaded-code execution exists.
