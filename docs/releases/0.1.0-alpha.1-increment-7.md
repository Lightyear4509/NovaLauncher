# 0.1.0-alpha.1 — Increment 7 UX hardening

## Delivered

- Five trusted built-in palettes: Nova Dark, Midnight Blue, Ember, Forest, and Nova Light
- Atomic persisted theme selection with runtime rollback on save failure
- Dynamic theme resources across the primary shell; downloaded themes remain prohibited
- Settings & Diagnostics page with local-only privacy and provider state
- Resource-keyed primary navigation strings and localization-ready boundaries
- Explicit focus-compatible controls, keyboard access keys, automation names,
  polite status announcements, and horizontally scrollable compact Library layout
- Deterministic 10,000-game warm-search p95 gate below 100 ms on the current runner
- Responsive Windows startup smoke coverage

## Release-readiness boundary

Automated accessibility contracts do not replace Narrator/NVDA and 200% scale
observation. This workstation has Windows Narrator but not NVDA and is Windows
11 build 26200; Windows 10 22H2 and clean-VM checks remain unavailable. Idle
working-set, scrolling frame pacing, five-run cold-start p95, and a multi-hour
soak still require the documented reference environment.
