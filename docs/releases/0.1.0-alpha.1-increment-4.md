# 0.1.0-alpha.1 — Increment 4 metadata and artwork

Increment 4 completes the alpha metadata and artwork vertical slice. It does
not make NovaLauncher packaged, release-ready, or feature complete.

## Delivered

- Deterministically ordered Steam metadata, Steam CDN artwork, and optional
  key-gated SteamGridDB providers
- Manual-precedence provenance merge, bounded fresh/stale caches, force refresh,
  cancellation, per-provider failures, and offline placeholders
- Bounded HTTPS artwork download with declared/detected format agreement,
  complete single-frame decode, byte/dimension/pixel ceilings, and generated names
- Managed-root durable installation, failed-commit rollback, obsolete-file
  cleanup, opaque persisted references, and safe UI rendering fallback
- Accessible refresh controls and a visually elevated selected-game hero panel

## Deliberately absent

Achievements, plugins, cloud saves, cross-device save linking, ROM acquisition,
telemetry, downloaded-code execution, packaging, and the later full navigation
redesign are not included.
