# 0.1.0-alpha.1 — Increment 0 foundation

This is a development foundation, not a distributable NovaLauncher release.

It contains the pinned solution structure, accessible themed shell, dependency
injection, structured local bootstrap logging, automated test projects, and CI
definition. Library management, importing, launching, providers, persistence,
packaging, signing, and the public release checklist remain incomplete.

## Toolchain

- .NET SDK 10.0.302
- Avalonia 12.1.1
- Windows x64 target

Build and test evidence must be recorded from the current source state; this
file does not substitute for command output.
