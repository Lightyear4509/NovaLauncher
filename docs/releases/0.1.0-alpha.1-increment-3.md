# 0.1.0-alpha.1 — Increment 3 defensive Steam import

Increment 3 adds read-only Steam discovery and an explicit preview/commit import
workflow. It is not a packaged release and does not make NovaLauncher complete.

## Added

- Supported Windows registry discovery plus manual absolute Steam root
- Bounded defensive Valve Data Format and application-manifest parser
- Current and legacy Steam library-folder discovery
- Per-file malformed, duplicate, unsafe, or missing-entry failures
- Stable namespaced identity derived from Steam App ID
- Revision-bound preview with add/update/unchanged/skipped counts
- One-save atomic merge that publishes only after persistence succeeds
- Accessible preview/import controls and live operation status
- Cancellation, stale-preview, failure isolation, reimport-preservation, and
  deterministic 10,000-game tests

## Safety boundary

Steam discovery reads no credentials, login files, authentication tokens, or
account data and never modifies Steam files. No metadata/artwork networking,
achievements, plugins, cloud saves, ROM acquisition, telemetry, packaging, or
downloaded-code execution is included.
