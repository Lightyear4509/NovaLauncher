## Verification

Locked restore, format verification, Debug build, Release build, packaging,
portable startup smoke, all 154 tests, coverage collection, and the transitive
NuGet vulnerability check passed. Test split: Domain 7, Application 49,
Infrastructure 94, Presentation 3, UI smoke 1; zero failed or skipped. Coverage
files were produced for all five test projects; instrumented line rates were
89.37%, 50.34%, 50%, and two 0% UI-host reports. Combining these independently
instrumented reports is not a meaningful solution-wide percentage.

After a user reported that the process started without a window, the startup
path was corrected to remove a UI-thread deadlock between synchronous theme
initialization and dispatcher palette application. A fresh normal-mode Release
binary and the packaged portable binary both produced a nonzero window handle
titled `NovaLauncher`, remained responsive, and closed cleanly. A regression
test prevents reintroducing the blocking startup call.
