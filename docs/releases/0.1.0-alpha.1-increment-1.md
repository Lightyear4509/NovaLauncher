# 0.1.0-alpha.1 — Increment 1 durable storage

Increment 1 adds the persistence foundation; it is not a distributable launcher.

## Added

- Stable game and collection identifiers
- Library item, launch target, metadata/provenance, collection, and settings models
- Independent schema-versioned games, collections, and settings documents
- Typed load/save outcomes and explicit legacy migration state
- Validated staged writes, durable flush, atomic replacement, and `.bak` recovery
- Corrupt-primary preservation and newer-schema overwrite refusal
- Cancellable cross-process file locks
- Validated export, restore preview, pre-restore backup, staged coordinated commit,
  and rollback after partial replacement failure
- Dependency-injection registration for all stores and backup service

## Still deferred

No library UI, manual game workflow, Steam import, game launching, providers,
plugins, cloud saves, ROM support, telemetry, installer, or release artifact is
included.
