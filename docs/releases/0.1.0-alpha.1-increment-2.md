# 0.1.0-alpha.1 — Increment 2 manual library

Increment 2 adds the first usable local manual-library workflow. It is not a
packaged release and does not make NovaLauncher feature-complete.

## Added

- Accessible three-pane Windows shell with first-run and recovery status
- Manual game add/edit and confirmed NovaLauncher-record removal
- Search, favorites-only filtering, and deterministic name/platform/recent sort
- Collection create, rename, confirmed delete, and membership changes
- Safe executable and allowlisted launcher-URI launch adapter
- Backup export plus validated, previewed, explicitly confirmed restore
- Focused application, infrastructure, presentation-contract, and responsive
  window startup tests

## Safety boundary

No plugin execution, downloaded-code execution, cloud saves, ROM acquisition,
telemetry, or storefront import is implemented. Removal does not touch installed
game files. Restore retains the Increment 1 pre-restore backup and rollback
boundary.
