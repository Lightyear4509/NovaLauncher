# Support Policy

NovaLauncher prereleases are community-supported on the repository's GitHub
Issues page. Include the NovaLauncher version, Windows version, display scale,
steps to reproduce, and the smallest useful sanitized diagnostic export. Do
not attach game files, saves, credentials, Tailnet addresses, API keys, or
copyrighted content.

Before reporting a defect, verify the release checksum, retry with the newest
release on the same selected channel, and confirm whether the issue occurs with
a clean portable copy. Preserve `%LOCALAPPDATA%\NovaLauncher` while diagnosing
an upgrade or migration issue.

Security issues follow `SECURITY.md` and must not be reported publicly.
Manual-game transfer remains experimental and is limited to content the user
is authorized to copy. Steam/store installation, licensing, multiplayer,
updates, and cloud services remain the responsibility of their providers.
